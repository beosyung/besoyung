# 우리 둘의 벽바둑 ♡ — 실시간 온라인 2인 대전

여자친구와 서로 다른 PC/휴대폰에서 **6자리 방 코드 또는 초대 링크**로 입장하는 웹게임입니다.

## 주요 기능

- 2명 전용 비공개 방(방 코드 6자리, 무작위 생성)
- 서버(WebSocket)가 게임판·턴·말 이동·벽 설치·점수를 검증하고 두 화면에 실시간 반영
- 7×7, 각자 말 4개(고정 2개 + 직접 배치 2개), 초기 배치 순서 빨강 → 파랑 → 파랑 → 빨강
- 이동 0~2칸, 벽 하나 설치, 연결된 영역 점수 및 승패 판정
- 링크 복사, 상대 입장/연결 종료 표시, 새로고침 후 자동 재접속, 재대결 동의, 이모티콘 응원
- 반응형 화면, 회원가입 불필요

> 주의: **게임이 완성된 것과 공개 사이트가 배포된 것은 다릅니다.** 서로 다른 인터넷 환경에서 접속하려면 아래 방식으로 공개 서버에 배포해야 합니다. HTML 파일만 각자 열어서는 온라인 동기화가 안 됩니다.

## 1. 내 컴퓨터에서 실행해보기

Node.js 22 이상 필요: https://nodejs.org/

**Windows**: 압축 해제 → `start_windows.bat` 더블클릭(추가 패키지 설치 불필요)

**Mac / Linux / 터미널**:

```bash
npm start
```

브라우저에서 http://localhost:3000 열기. 다른 기기와 테스트하려면 실제 인터넷 배포가 필요합니다(로컬 네트워크라면 방화벽과 PC IP 등 별도 설정 필요).

## 2. Render에 공개 배포하기

아래는 Render의 일반적인 GitHub 연동 배포 경로이며 Render UI와 무료 플랜 정책은 변경될 수 있습니다.

1. https://github.com 에 로그인하여 새 **비공개(Private)** 저장소 생성
2. 이 폴더의 **전체 내용**을 저장소 루트에 업로드 (`server.js`, `package.json`, `public/` 등 파일 계층 유지)
3. https://dashboard.render.com 에 로그인 → **New → Web Service**
4. GitHub 저장소 연결, 설정:
   - Language: **Node**
   - Build Command: `npm install` (외부 의존성 없음)
   - Start Command: `npm start`
   - Instance Type: 가능한 경우 Free
5. **Deploy** 진행 → 배포가 끝나면 `https://...onrender.com` 주소가 만들어짐
6. 두 사람이 그 주소로 접속. 한 사람이 `방 만들기` → 초대 링크 복사 → 다른 사람에게 전송

`render.yaml`도 포함되어 있으므로 Render의 Blueprint 방식으로 배포해도 됩니다.

**중요**: Render 무료 인스턴스는 비활성 시 절전 상태가 될 수 있습니다. 서버가 재시작되면 메모리 안에 있던 방과 대국 기록은 사라집니다. 장기 기록 보관/항상 켜짐이 필요하면 DB와 유료 호스팅 등이 추가로 필요합니다. 모바일에서는 앱을 백그라운드로 두면 연결이 잠시 끊어질 수 있고 다시 열면 자동 복귀합니다.

## 3. 사용 방법

- ① 내가 빨강으로 방 만들기 → `♡ 초대 링크 복사`
- ② 여자친구에게 링크 전달 → 링크를 열고 닉네임 입력 후 `입장하기`
- ③ 양쪽이 연결되면 말 배치 시작
- ④ 내 말 선택 → 이동할 칸 선택 → 하이라이트된 벽 클릭
- ⑤ 종료 후 둘 다 재대결 동의하면 새 판 시작

## 보안과 한계

- 사용자 인증이나 암호가 아니라 방 코드/로컬 재접속 토큰을 사용합니다. 방 코드를 아는 다른 사람이 상대가 들어오기 전에 참여할 수 있으니 링크를 공개하지 마세요.
- 서버가 수를 검증하고 말이나 턴을 임의로 바꾸는 요청을 거절합니다.
- 서버 저장소는 메모리입니다. 다시 접속하면 진행 중이던 판을 불러오지만 **서버 재시작 후에는 복구되지 않습니다.**
- 인터넷 없이 두 사람이 각각 HTML 파일을 열어서 대국할 수는 없습니다.
- 원작 TV 프로그램과 공식 제휴한 서비스가 아닙니다. 고정 시작 말 위치는 대칭형(A3, A5 / G3, G5)으로 구성했습니다.
