# 벽바둑 2 · 2인전 규칙 검증

대상은 2026년 《데블스 플랜: 데드 어게인》 시즌 3 제10회, 네 번째 감옥 매치 중 유리사와 존박의 2인전이다. 넷플릭스 공식 발표로 시즌을 식별하고, 10회의 공개 한국어·영어 자막 전사에서 딜러 설명, 연습 장면과 실제 대국의 호명을 대조했다. 두 언어의 자막은 같은 방송에 기반한다. 방송 원본 영상이나 제작사의 도면을 직접 검수한 것은 아니다.

| 항목 | 확인한 내용 | 근거 |
|---|---|---|
| 판 크기 | 7행 × 7열, 49칸 | 영어 전사 2522–2526, 한국어 대국 해설 |
| 말과 배치 | 각자 원형 2개가 사전 배치되고 사각 2개를 직접 놓는다. 네 번의 배치 뒤 선공이 먼저 움직인다. | 영어 2400–2439. 딜러가 실제로 유리사 → 존박 → 존박 → 유리사를 호명 |
| 원형 이동 | 상하좌우 1칸에서 멈추거나, 거기서 직각으로 한 칸 더 이동한다. 빈 판 중앙에서 목적지는 여덟 곳이다. 대각선 목적지는 두 직각 경로 중 한 경로가 열리면 도달한다. | 한국어 딜러의 선택형 설명과 영어 1841–1849, 1860–1872의 연습 대화 |
| 사각 이동 | 한 직선으로 1칸 또는 2칸. 임의 패스 및 원위치로 돌아오는 수는 허용하지 않는다. | 한국어 딜러 설명, 영어 1849–1872 |
| 충돌 | 말이 있는 칸에 들어가거나 벽을 관통할 수 없다. 중간 칸과 두 번째 변까지 차례대로 검사한다. 2인전에서 벽을 부술 수 없다. | 두 언어의 이동 설명, 영어 2404–2408 |

| 종료와 점수 | 벽에 의해 서로 다른 색 말의 영역이 모두 분리되면 즉시 종료한다. 각자의 말이 들어 있는 영역 크기를 합산한다. | 한국어·영어 딜러 설명. 2인전 직전에도 넓은 영역을 가진 사람의 승리를 재안내 |
| 동점 | 공통 설명에서 합계 동률 시 가장 큰 개별 영역의 넓이를 비교한다. 2인전 소개에서 이 항목을 다시 설명하지는 않으므로 공통 설명을 적용하는 해석이다. | 영어 자막 2인전 소개 직전 순위 규정 |
| 제한 시간 | 이동과 벽 설치를 합쳐 90초. 딜러는 시간 초과 시 임의의 벽을 설치한다고 설명한다. 이동하기 전에 시간을 초과한 사례의 후속 판정은 확인되지 않았다. | 한국어·영어 규칙 소개, 영어 2437–2439 |

### 화면에서 확정하지 못한 사항

- 고정 원형 말의 색별 네 좌표를 자막이 호명하지 않는다. 따라서 앱의 기본 좌표는 임시 배치로 취급한다. 방송을 대조할 때에는 첫 사각 말을 놓기 직전의 2인전 판 전체가 필요하다. 3인전 화면에서는 모든 말을 직접 놓으므로 구별해야 한다.
- 같은 색 말 여러 개가 든 영역은 한 번만 합산하고 말 없는 영역은 0점으로 보는 것이 영역 단위 집계의 해석이다. 진행 중 두 색 말이 함께 있는 영역은 확정 점수에 포함하지 않는다.
- 자기 말 전부가 움직이지 못하는 경우와 최대 단일 영역까지 동일한 경우의 후속 절차는 자료에서 확인되지 않았다. 앱의 해당 처리는 온라인 대국 운영 규칙이다.
- 방송의 선공은 전 라운드 성적에서 정했다. 독립된 2인전 서비스의 선공 배정과 타이머 끄기는 앱에서 선택한 방식이다.
